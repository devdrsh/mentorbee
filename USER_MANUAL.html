📌 1. System Architecture & Workflow

MentorBee Class Link Management System is engineered to eliminate manual link errors, delays, and WhatsApp formatting inconsistencies across 106+ educational batches spanning 8th, 9th, 10th, 11th Science/Commerce, and 12th Science/Commerce (both State Syllabus and CBSE).

⚡ High-Speed Scheduling

Coordinators paste raw WhatsApp meeting invites. The smart regex engine extracts the Zoom URL, Meeting ID, and Passcode in milliseconds.

🔄 Real-Time WebSocket Sync

Newly scheduled classes or link modifications reflect instantly across all active mentor dashboards without manual refresh.

📱 Mobile-First Mentor UI

Clean, high-contrast touch interface with 1-click WhatsApp message copying and direct Zoom deep-linking.

🛡️ Security & Full Audit Trail

Every login, message copy, link copy, and Zoom launch is timestamped with staff name, class scope, and IP address.
🔄 End-to-End Operational Lifecycle
Step 1: Faculty creates Zoom meeting > Step 2: Coordinator pastes invite text into Admin Portal > Step 3: System parses details and publishes session > Step 4: WebSocket pushes update to Mentor Portals > Step 5: Mentor taps "Copy Message" and dispatches to WhatsApp student groups.

🛠️ 3. Admin & Coordinator Portal (`/admin`)

The Administrative Console allows Super Admins and Class Coordinators to manage live sessions, batch catalogs, and audit logs.

3.1 Top Navigation & Identity Status

  • Logo & Home link: Quickly identify the platform and branding.
  • User Badge: Displays logged-in coordinator name with a green status indicator and their authorized class scope (e.g. COORD: 10TH or SUPER ADMIN).
  • Mentor Portal Shortcut (`↗`): Opens the live mentor dashboard in a new tab for rapid testing.
  • Logout Button: Destroys session token and returns securely to the login portal.

3.2 Tab 1: Sessions Management

The primary command center for scheduling and broadcasting Zoom sessions.

⚡ How to Create a Class Session (Step-by-Step)
  1. Open Create Modal: Click the golden + Create Session button in the top right.
  2. Smart Zoom Paste Auto-Fill (Recommended):
    Paste the raw WhatsApp text received from the teacher into the ⚡ Quick Zoom Paste Auto-Fill textarea.
    Click Auto Parse Link & Credentials. The system instantly extracts the Zoom URL, Meeting ID, and Passcode and fills them into their respective fields.
  3. Select Class Stream & Batch:
    Select the Assigned Class Stream (e.g. 10th Class).
    Optionally filter by Syllabus Filter (CBSE or STATE).
    Select the exact target Batch from the filtered dropdown list.
  4. Enter Class Topic & Schedule:
    Type the Class Topic / Subject (e.g. Mathematics - Quadratic Equations).
    Set the Date (defaults to today) and Start Time (IST).
  5. Publish & Broadcast:
    Click Save & Broadcast Session.
    The session is committed to the database, formatted messages are pre-computed, and an instant WebSocket broadcast triggers updates across all mentor dashboards.

✏️ Editing Sessions

Click Edit on any session row. You can modify the topic, link, time, or passcode on the fly. All changes are logged in the version change history and instantly updated for mentors.

🗑️ Deleting Sessions

Click Delete on any session row. A confirmation prompt prevents accidental deletion. Once confirmed, the session is removed permanently and cleared from mentor views.

3.3 Tab 2: Batches Management

Maintains the institution's catalog of all active academic batches.

Key Functions in Batches Tab

  • Batch Inventory: Displays Batch ID, Assigned Class Category, Full Batch Name, Syllabus (CBSE or STATE), and Active Status.
  • Class Scope Isolation: Coordinators only view batches matching their assigned grades. Super Admin views all 106+ batches.
  • Create New Batch: Click + Create Batch, enter the name (e.g. 10TH STATE EVNG KL BATCH). The system automatically infers syllabus and grade categories from the naming pattern.
  • Edit Batch: Rename or update batch metadata whenever class structures evolve.

📞 6. Operational Troubleshooting & FAQs

Q1: Passcode rejected during Mentor Login?

Solution: Ensure you are using the Master Staff Passcode AGENTBEE0809 or the class-specific passcode matching your selected class. Passcodes are case-insensitive.

Q2: No batches appear in the "Select Batch" dropdown when creating a session?

Solution: Check the Syllabus Filter in the creation modal. If it is set to "CBSE" and you selected an 11th Commerce class with only State batches, switch the filter to "All Syllabuses".

Q3: Zoom Auto-Extractor fails to parse invite text?

Solution: Verify that the pasted WhatsApp message contains a valid https://zoom.us/j/... URL. If the message only has Meeting ID and Passcode, enter the values manually into the corresponding fields.

Q4: How does real-time synchronization work if a link changes last minute?

Solution: When a coordinator edits a session, the backend broadcasts a WebSocket message and mentor devices automatically reload data within milliseconds. In addition, the mentor portal runs an automatic background poll every 4 seconds as a fail-safe.
